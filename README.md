# ImageMetadataStegoTool

Графическое приложение для скрытия файлов и текста в изображениях.
Реализовано на C# с использованием кроссплатформенного фреймворка Avalonia UI.

## Основные возможности

- **Кодирование (Скрытие данных):**
  - Возможность спрятать произвольный текст или файл (весом до 1 КБ) внутри изображения (поддерживаются форматы `.png`, `.jpg`, `.jpeg`).
  - Поддержка перетаскивания файлов (Drag & Drop) для быстрого добавления внедряемых данных и картинок-контейнеров.
  - Автоматическое сохранение полученных изображений в папку приложения и возможность экспорта в любое другое место.

- **Декодирование (Извлечение данных):**
  - Чтение скрытого текста или извлечение встроенного файла из заранее закодированного изображения.
  - Автоматическое сохранение извлеченных файлов в папку приложения и возможность их экспорта на диск.

- **Интерфейс:**
  - Простой, интуитивно понятный графический UI с возможностью выбора файлов через диалоговые окна или перетаскиванием.

## Технологии

- **Платформа:** .NET 8
- **Язык:** C# 12
- **UI-фреймворк:** Avalonia UI

## Как использовать

### Скрытие данных (Кодирование)
1. Введите текст в соответствующее поле **ИЛИ** прикрепите файл, который хотите спрятать (через Drag & Drop или кнопку выбора файла).
2. Выберите оригинальное изображение-контейнер (`.png`, `.jpg` или `.jpeg`).
3. Нажмите кнопку кодирования (Encode). Готовое изображение автоматически сохранится в соответствующей папке рядом с приложением.
4. При необходимости воспользуйтесь кнопкой сохранения, чтобы выбрать любое удобное место на диске.

### Извлечение данных (Декодирование)
1. Выберите изображение, содержащее скрытые данные.
2. Нажмите кнопку декодирования (Decode).
3. Приложение отобразит скрытый текст или извлечет файл. Результаты автоматически сохраняются в соответствующих папках рядом с приложением.
4. При необходимости воспользуйтесь кнопкой сохранения, чтобы выгрузить данные в любое другое место на диске.
